# Карта репозитория

Рабочее приложение находится в [quickstart-pytorch/](quickstart-pytorch/). Один эксперимент запускает `scripts/run_experiment.py`. Корневой `main.py` только печатает приветствие. Команды запуска приведены в [README приложения](quickstart-pytorch/README.md).

## Запуск и настройки

Все пути в этой и следующих двух таблицах указаны от `quickstart-pytorch/`.

| Файл | За что отвечает |
| --- | --- |
| `pyproject.toml` | Зависимости, точки входа Flower и параметры эксперимента по умолчанию. |
| `configs/*.toml` | Готовые сценарии. Например, `ham10000_dirichlet.toml` задаёт отдельный эксперимент, а `aggregation_pilot.toml` — серию для сравнения стратегий. |
| `scripts/run_experiment.py` | Объединяет настройки из TOML и командной строки, создаёт каталог запуска и вызывает Flower. |
| `scripts/run_benchmark.py`, `pytorchexample/benchmark.py` | Скрипт запускает серию. Модуль разворачивает план, сохраняет прогресс и проверяет, какие запуски можно использовать повторно. |
| `scripts/collect_benchmark.py` | Собирает результаты серии в общую CSV-таблицу. |

## Что происходит в одном раунде

Сервер рассылает общие веса → клиенты обучают модель на своих данных → сервер объединяет обновления и оценивает результат.

| Файл в `pytorchexample/` | За что отвечает |
| --- | --- |
| `server_app.py` | Создаёт общую модель, запускает раунды и организует оценку качества. |
| `client_app.py` | Получает веса, выбирает данные своего клиента, вызывает локальное обучение и возвращает результат. |
| `task.py` | Определяет архитектуру CNN, загрузку и разбиение данных между клиентами, расчёт метрик классификации. |
| `strategies.py` | По имени стратегии выбирает серверную стратегию и соответствующий клиентский алгоритм. |
| `local_training.py` | Реализует шаги обучения модели на клиенте. |
| `custom_strategies.py` | Реализует серверную часть FedNova и SCAFFOLD. |
| `experiment.py`, `experiment_plots.py` | Первый записывает результаты эксперимента, второй строит графики по раундам. |

## Данные и неоднородность

| Файл | За что отвечает |
| --- | --- |
| `scripts/prepare_cifar10.py`, `scripts/prepare_ham10000.py` | Готовят CIFAR-10 и HAM10000 соответственно. |
| `scripts/prepare_candidate_dataset.py`, `pytorchexample/dataset_adapters.py` | Скрипт запускает подготовку FER2013 или Cassava. Модуль содержит обработку каждого набора. |
| `scripts/analyze_heterogeneity.py` | Измеряет различия в распределении классов между клиентами без обучения модели. |
| `pytorchexample/heterogeneity.py`, `pytorchexample/heterogeneity_plots.py` | Вычисляют показатели неоднородности и строят графики соответственно. |
| `scripts/build_heterogeneity_atlas.py` | Сводит показатели для разных значений параметра Дирихле α и разных seed. |

## Где искать результаты и материалы

- В `quickstart-pytorch/results/` хранятся запуски. В каталоге эксперимента `experiment.json` содержит настройки и статус, `round_metrics.csv` — метрики по раундам, `console.log` — вывод Flower.
- В `quickstart-pytorch/data/` лежат локальные наборы данных, в `dataset_examples/` рядом — примеры изображений и распределений. Наборы описаны в `DATASET.md`, `DATASET_COMPARISON.md` и `HAM10000.md` приложения.
- В `quickstart-pytorch/tests/` лежат тесты по модулям. Например, `test_metrics.py` проверяет метрики, а `test_custom_strategies.py` — серверные алгоритмы.
- В корне проекта `исследование/` содержит план исследования, `источники/` — литературу и обзоры. В обеих папках `docs/` хранятся технические планы, а в `updates.md` — описание ранней версии проекта.
