# План реализации сравнения несбалансированных наборов данных

> **Для Codex:** Выполняйте этот план последовательно, задача за задачей. Для каждого изменения кода используйте разработку через тестирование и перед отчётом о завершении запускайте полный набор проверок.

**Цель:** Сравнить несколько наборов данных для классификации изображений с естественным дисбалансом, технически проверить три репрезентативных кандидата и документировать воспроизводимое обоснование выбора набора данных для экспериментов в магистерской диссертации.

**Архитектура:** Отделить отбор на основе литературы от исполняемой подготовки наборов данных. Небольшой модуль адаптеров приведёт FER2013 и Cassava Leaf Disease 2020 к той же границе локальных CSV-манифестов, которая уже используется для HAM10000; конвейер данных Flower будет использовать эти манифесты без добавления исходных изображений в репозиторий. Научное сравнение и взвешенное оценивание будут задокументированы в отдельном Markdown-отчёте, подкреплённом ссылками на первоисточники и наблюдаемыми результатами проверок работоспособности.

**Технологический стек:** Python 3.11+, PyTorch, Hugging Face Datasets, Pillow, kagglehub, unittest, Flower.
