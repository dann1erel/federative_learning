# Естественно несбалансированный набор данных HAM10000

## Выбор

Для серии экспериментов с естественным глобальным дисбалансом выбран **HAM10000** — набор дерматоскопических RGB-изображений семи типов пигментных поражений кожи. Используется зеркало Kaggle [`eliocordeiropereira/skin-cancer-the-ham10000-dataset`](https://www.kaggle.com/datasets/eliocordeiropereira/skin-cancer-the-ham10000-dataset), потому что оно содержит не только 10 015 обучающих изображений и метаданные, но и изображения с разметкой официальной тестовой выборки ISIC 2018 Task 3.

Первичные источники:

- [HAM10000, Harvard Dataverse, версия 4](https://doi.org/10.7910/DVN/DBW86T);
- [Tschandl, Rosendahl, Kittler, Scientific Data, 2018](https://doi.org/10.1038/sdata.2018.161);
- [страница набора данных на Kaggle](https://www.kaggle.com/datasets/eliocordeiropereira/skin-cancer-the-ham10000-dataset).

Лицензия зеркала и исходных данных — **CC BY-NC 4.0**: разрешено академическое некоммерческое использование с указанием авторства.

## Распределение классов

HAM10000 имеет естественный дисбаланс исходной разметки:

| Идентификатор | Код | Тип поражения | Изображений | Доля |
|---:|---|---|---:|---:|
| 0 | `akiec` | актинический кератоз / внутриэпителиальная карцинома | 327 | 3,27% |
| 1 | `bcc` | базальноклеточная карцинома | 514 | 5,13% |
| 2 | `bkl` | доброкачественные кератозоподобные образования | 1 099 | 10,97% |
| 3 | `df` | дерматофиброма | 115 | 1,15% |
| 4 | `mel` | меланома | 1 113 | 11,11% |
| 5 | `nv` | меланоцитарные невусы | 6 705 | 66,95% |
| 6 | `vasc` | сосудистые образования | 142 | 1,42% |

Отношение крупнейшего класса `nv` к редчайшему `df` равно `6705 / 115 ≈ 58,3`. Поэтому обычная точность может быть высокой даже у модели, почти всегда выбирающей `nv`. Основные показатели этой серии — макро-F1, сбалансированная точность (макро-полнота), полнота по каждому классу и матрица ошибок.

## Что именно исследуется

HAM10000 дополняет CIFAR-10, а не заменяет его:

| Набор | Глобальный дисбаланс классов | Неоднородность клиентов | Роль |
|---|---|---|---|
| CIFAR-10 | нет | синтетическая IID/Дирихле | контролируемый эталонный набор |
| HAM10000 | сильный, естественный | естественная или IID/Дирихле | более реалистичная стресс-проверка |

Поддерживаются три типа федеративного разбиения:

1. `iid` — клиенты получают случайные группы поражений, но сохраняют глобальный дисбаланс.
2. `dirichlet` — глобальный дисбаланс сочетается с дополнительным перекосом распределения меток и объёмов данных.
3. `natural` — четыре клиента соответствуют исходным коллекциям из поля `dataset`: `rosendahl`, `vidir_modern`, `vidir_molemax`, `vienna_dias`. Это одновременно создаёт естественные перекосы распределения меток, объёмов данных и предметных областей.

Фактически подготовленное естественное разбиение имеет следующий вид:

| Идентификатор клиента | Источник | Всего объектов | Пример неоднородности |
|---:|---|---:|---|
| 0 | `rosendahl` | 2 259 | `akiec=295`, `nv=803`, `vasc=3` |
| 1 | `vidir_modern` | 3 372 | `mel=689`, `nv=1 832` |
| 2 | `vidir_molemax` | 3 945 | `nv=3 720`, отсутствует `akiec` |
| 3 | `vienna_dias` | 439 | отсутствует `akiec`, только 3 `vasc` |

Девять `lesion_id` имеют изображения, приписанные двум исходным коллекциям. Чтобы не нарушать групповую целостность, все снимки такого поражения назначаются источнику большинства; при равенстве используется детерминированный лексикографический выбор. Поэтому итоговые размеры `vidir_modern` и `vidir_molemax` немного отличаются от простого подсчёта строк исходного CSV-файла метаданных.

## Защита от утечки данных

В HAM10000 10 015 изображений соответствуют 7 470 уникальным поражениям: одно поражение иногда снято несколько раз. Случайное разбиение по изображениям может поместить почти одинаковые снимки в обучающую и проверочную выборки.

Реализация использует `lesion_id` как неделимую группу:

- все изображения одного поражения назначаются одному федеративному клиенту;
- локальные разбиения на обучающую и проверочную выборки также выполняются по `lesion_id`;
- официальная тестовая выборка ISIC 2018 остаётся централизованной и не балансируется;
- если используется старое зеркало без официальной тестовой выборки, скрипт подготовки создаёт групповую отложенную выборку без пересечения `lesion_id`.

В выбранном зеркале Kaggle разметка содержит 1 512 официальных тестовых строк, но отсутствует файл `ISIC_0035068.jpg` класса `nv`. Скрипт явно сообщает об этом и формирует проверенный манифест тестовой выборки из 1 511 доступных изображений; пропуск также фиксируется в `summary.json`.

## Загрузка

Изображения весят около 3,2 ГБ, поэтому они не добавляются в Git. Официальная библиотека `kagglehub` сохраняет их в пользовательском кэше, а проект хранит только небольшие CSV-манифесты с путями:

```bash
cd quickstart-pytorch
python scripts/prepare_ham10000.py
```

Для публичного зеркала авторизация обычно не нужна. Если Kaggle запросит согласие или авторизацию, нужно создать токен API в настройках Kaggle и установить переменную `KAGGLE_API_TOKEN`, после чего повторить команду. Поддерживается и уже скачанный каталог:

```bash
python scripts/prepare_ham10000.py --source-dir /path/to/HAM10000
```

Скрипт создаёт:

- `data/ham10000/train.csv` и `test.csv` — локальные манифесты; каталог `data/` исключён из Git;
- `dataset_examples/ham10000/ham10000_samples.png` — примеры всех классов;
- `class_distribution.csv` и `class_distribution.png`;
- CSV-файлы и тепловые карты распределений по клиентам для естественного разбиения, IID и распределения Дирихле `alpha=1.0/0.5/0.1`;
- `summary.json` с точными параметрами, размерами и показателями неоднородности.

## Запуск федеративного обучения

Контрольный запуск без компенсации глобального дисбаланса:

```bash
flwr run . --run-config \
  "dataset='ham10000' partitioner='iid' class-weighting='none' seed=42" \
  --stream
```

Тот же сценарий с глобальными весами `N / (K · n_c)` в `CrossEntropyLoss`:

```bash
flwr run . --run-config \
  "dataset='ham10000' partitioner='iid' class-weighting='balanced' seed=42" \
  --stream
```

Сочетание исходного дисбаланса и сильного клиентского перекоса распределения меток:

```bash
flwr run . --run-config \
  "dataset='ham10000' partitioner='dirichlet' dirichlet-alpha=0.1 class-weighting='balanced' seed=42" \
  --stream
```

Естественное разбиение требует ровно четыре SuperNode:

```bash
flwr run . \
  --run-config "dataset='ham10000' partitioner='natural' class-weighting='balanced' seed=42" \
  --federation-config "options.num-supernodes=4" \
  --stream
```

Для корректного вывода сначала следует сравнить `none` и `balanced` при IID, затем повторить сравнение при разбиениях Дирихле и естественном разбиении. Начальное значение генератора, модель, число раундов и локальных эпох должны совпадать.

Готовые воспроизводимые переопределения параметров находятся в `configs/`:

```bash
flwr run . --run-config configs/ham10000_iid.toml --stream
flwr run . --run-config configs/ham10000_dirichlet.toml --stream
flwr run . --run-config configs/ham10000_natural.toml \
  --federation-config "options.num-supernodes=4" --stream
```

## Единая оценка неоднородности и агрегаций

Для сопоставимости с CIFAR-10 основной пилот использует 10 клиентов и
Dirichlet `alpha=0.5`; естественное разбиение по четырём источникам остаётся
отдельным последующим сценарием. Численные показатели и диагностические
графики строятся командой:

```bash
python scripts/analyze_heterogeneity.py \
  --dataset ham10000 --dataset-root data/ham10000 \
  --partitioner dirichlet --dirichlet-alpha 0.5 \
  --num-clients 10 --seed 42
```

HAM10000 требует разделять два эффекта:

- глобальный дисбаланс классов измеряют entropy, class Gini,
  majority/minority ratio и QCID;
- межклиентскую неоднородность измеряют расстояния каждого клиента до
  глобального распределения, попарные расстояния, quantity skew и class
  coverage.

Иначе даже IID-разбиение HAM10000 ошибочно выглядит неоднородным только из-за
глобального преобладания `nv`. Анализатор дополнительно сохраняет число
уникальных `lesion_id` клиента. Изображения при расчёте не декодируются, а
групповая целостность совпадает с обучающим конвейером.

Пилот всех девяти стратегий и итоговая таблица запускаются командами из
раздела «Сравнение агрегаций и метрики неоднородности» в `README.md`.

## Ограничения и этика

- Это учебный исследовательский эталонный набор, а не система клинической диагностики.
- Класс и источник изображения могут коррелировать с оборудованием, клиникой и популяцией, поэтому модель способна выучить нежелательные побочные признаки.
- Изменение размера до `64 × 64` позволяет использовать лёгкую CNN, но приводит к потере части диагностических деталей. Для итогового медицинского исследования нужна более подходящая архитектура и более высокое разрешение.
- Функция потерь с весами классов не создаёт новых данных редких классов и не решает все проявления дисбаланса; она используется как прозрачный базовый уровень.
- Из-за ограничения на некоммерческое использование набор данных нельзя применять в коммерческих продуктах без отдельного разрешения.
