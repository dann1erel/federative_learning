# Естественно несбалансированный датасет HAM10000

## Выбор

Для второй серии экспериментов выбран **HAM10000** — набор дерматоскопических RGB-изображений семи типов пигментных поражений кожи. Используется Kaggle-зеркало [`eliocordeiropereira/skin-cancer-the-ham10000-dataset`](https://www.kaggle.com/datasets/eliocordeiropereira/skin-cancer-the-ham10000-dataset), потому что оно содержит не только 10 015 обучающих изображений и метаданные, но и изображения с разметкой официального test-набора ISIC 2018 Task 3.

Первичные источники:

- [HAM10000, Harvard Dataverse, версия 4](https://doi.org/10.7910/DVN/DBW86T);
- [Tschandl, Rosendahl, Kittler, Scientific Data, 2018](https://doi.org/10.1038/sdata.2018.161);
- [страница датасета на Kaggle](https://www.kaggle.com/datasets/eliocordeiropereira/skin-cancer-the-ham10000-dataset).

Лицензия зеркала и исходных данных — **CC BY-NC 4.0**: разрешено академическое некоммерческое использование с указанием авторства.

## Распределение классов

HAM10000 имеет естественный, а не искусственно созданный дисбаланс:

| ID | Код | Тип поражения | Изображений | Доля |
|---:|---|---|---:|---:|
| 0 | `akiec` | actinic keratoses / intraepithelial carcinoma | 327 | 3,27% |
| 1 | `bcc` | basal cell carcinoma | 514 | 5,13% |
| 2 | `bkl` | benign keratosis-like lesions | 1 099 | 10,97% |
| 3 | `df` | dermatofibroma | 115 | 1,15% |
| 4 | `mel` | melanoma | 1 113 | 11,11% |
| 5 | `nv` | melanocytic nevi | 6 705 | 66,95% |
| 6 | `vasc` | vascular lesions | 142 | 1,42% |

Отношение крупнейшего класса `nv` к редчайшему `df` равно `6705 / 115 ≈ 58,3`. Поэтому обычная accuracy может быть высокой даже у модели, почти всегда выбирающей `nv`. Основные показатели этой серии — `macro F1`, `balanced accuracy` (macro recall), per-class recall и confusion matrix.

## Что именно исследуется

HAM10000 дополняет CIFAR-10, а не заменяет его:

| Набор | Глобальный class imbalance | Неоднородность клиентов | Роль |
|---|---|---|---|
| CIFAR-10 | нет | искусственная IID/Dirichlet | контролируемый benchmark |
| HAM10000 | сильный, естественный | естественная или IID/Dirichlet | более реалистичный стресс-тест |

Поддерживаются три типа федеративного разбиения:

1. `iid` — клиенты получают случайные группы поражений, но сохраняют глобальный дисбаланс.
2. `dirichlet` — глобальный дисбаланс сочетается с дополнительным label/quantity skew.
3. `natural` — четыре клиента соответствуют исходным коллекциям из поля `dataset`: `rosendahl`, `vidir_modern`, `vidir_molemax`, `vienna_dias`. Это одновременно создаёт естественные label-, quantity- и domain-skew.

Фактически подготовленное natural-разбиение имеет следующий вид:

| Client ID | Источник | Всего объектов | Пример неоднородности |
|---:|---|---:|---|
| 0 | `rosendahl` | 2 259 | `akiec=295`, `nv=803`, `vasc=3` |
| 1 | `vidir_modern` | 3 372 | `mel=689`, `nv=1 832` |
| 2 | `vidir_molemax` | 3 945 | `nv=3 720`, отсутствует `akiec` |
| 3 | `vienna_dias` | 439 | отсутствует `akiec`, только 3 `vasc` |

Девять `lesion_id` имеют изображения, приписанные двум исходным коллекциям. Чтобы не нарушать групповую целостность, все снимки такого поражения назначаются источнику большинства; при равенстве используется детерминированный лексикографический выбор. Поэтому итоговые размеры `vidir_modern` и `vidir_molemax` немного отличаются от простого подсчёта строк исходного metadata CSV.

## Защита от утечки данных

В HAM10000 10 015 изображений соответствуют 7 470 уникальным поражениям: одно поражение иногда снято несколько раз. Случайное разбиение по изображениям может поместить почти одинаковые снимки в train и validation.

Реализация использует `lesion_id` как неделимую группу:

- все изображения одного поражения назначаются одному федеративному клиенту;
- локальные train/validation-разбиения также выполняются по `lesion_id`;
- официальный ISIC 2018 test-набор остаётся централизованным и не балансируется;
- если используется старое зеркало без официального test-набора, preparation-скрипт создаёт групповой holdout без пересечения `lesion_id`.

В выбранном Kaggle-зеркале разметка содержит 1 512 официальных test-строк, но отсутствует файл `ISIC_0035068.jpg` класса `nv`. Скрипт явно сообщает об этом и формирует проверенный test manifest из 1 511 доступных изображений; пропуск также фиксируется в `summary.json`.

## Загрузка

Изображения весят около 3,2 ГБ, поэтому они не добавляются в Git. Официальная библиотека `kagglehub` сохраняет их в пользовательском кэше, а проект хранит только небольшие CSV-манифесты с путями:

```bash
cd quickstart-pytorch
python scripts/prepare_ham10000.py
```

Для публичного зеркала авторизация обычно не нужна. Если Kaggle запросит согласие или авторизацию, нужно создать API token в настройках Kaggle и установить переменную `KAGGLE_API_TOKEN`, после чего повторить команду. Поддерживается и уже скачанный каталог:

```bash
python scripts/prepare_ham10000.py --source-dir /path/to/HAM10000
```

Скрипт создаёт:

- `data/ham10000/train.csv` и `test.csv` — локальные манифесты; каталог `data/` исключён из Git;
- `dataset_examples/ham10000/ham10000_samples.png` — примеры всех классов;
- `class_distribution.csv` и `class_distribution.png`;
- CSV и heatmap распределений по клиентам для natural, IID и Dirichlet `alpha=1.0/0.5/0.1`;
- `summary.json` с точными параметрами, размерами и показателями неоднородности.

## Запуск федеративного обучения

Контрольный запуск без компенсации глобального дисбаланса:

```bash
flwr run . --run-config \
  "dataset='ham10000' partitioner='iid' class-weighting='none' seed=42" \
  --stream
```

Тот же сценарий с глобальными весами `N / (K · n_c)` в `CrossEntropyLoss`:

```bash
flwr run . --run-config \
  "dataset='ham10000' partitioner='iid' class-weighting='balanced' seed=42" \
  --stream
```

Сочетание исходного дисбаланса и сильного клиентского label skew:

```bash
flwr run . --run-config \
  "dataset='ham10000' partitioner='dirichlet' dirichlet-alpha=0.1 class-weighting='balanced' seed=42" \
  --stream
```

Естественное разбиение требует ровно четыре SuperNode:

```bash
flwr run . \
  --run-config "dataset='ham10000' partitioner='natural' class-weighting='balanced' seed=42" \
  --federation-config "options.num-supernodes=4" \
  --stream
```

Для корректного вывода сначала следует сравнить `none` и `balanced` при IID, затем повторить сравнение при Dirichlet и natural-разбиениях. Seed, модель, число раундов и локальных эпох должны совпадать.

Готовые воспроизводимые overrides находятся в `configs/`:

```bash
flwr run . --run-config configs/ham10000_iid.toml --stream
flwr run . --run-config configs/ham10000_dirichlet.toml --stream
flwr run . --run-config configs/ham10000_natural.toml \
  --federation-config "options.num-supernodes=4" --stream
```

## Ограничения и этика

- Это учебный исследовательский benchmark, а не система клинической диагностики.
- Класс и источник изображения могут коррелировать с оборудованием, клиникой и популяцией, поэтому модель способна выучить нежелательные shortcut-признаки.
- Resize до `64 × 64` позволяет использовать лёгкую CNN, но теряет часть диагностических деталей. Для итогового медицинского исследования нужна более подходящая архитектура и более высокое разрешение.
- Class-weighted loss не создаёт новых данных редких классов и не решает все проявления дисбаланса; он добавлен как прозрачный baseline.
- Из-за ограничения NonCommercial датасет нельзя применять в коммерческих продуктах без отдельного разрешения.
