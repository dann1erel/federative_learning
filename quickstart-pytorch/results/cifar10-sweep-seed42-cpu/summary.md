# CIFAR-10, seed 42 · Сравнение девяти стратегий

Завершены 72 запуска. Во всех случаях глобальную CNN оценивали на одних и тех же 10 000 тестовых изображений после каждого раунда, включая исходную модель. Величина Q — средний macro-F1 за раунды 46–50. Изменение в п.п. и сохранённая доля учитывают собственный IID-результат каждой стратегии.

## Порог потери качества

Для каждого порога указано первое измеренное разбиение в порядке возрастания HD. В скобках приведён процент от собственного IID. Возврат выше порога указан при его наличии.

| Стратегия | Q на IID | Осталось ≤95% | Осталось ≤90% |
|---|---:|---|---|
| FedAvg | 59.38% | α=0.5, HD 0.406 (92.6%) | α=0.2, HD 0.549 (86.9%) |
| FedAvgM | 53.02% | α=1, HD 0.290 (92.0%) | α=0.5, HD 0.406 (88.6%) |
| FedProx | 59.48% | α=0.5, HD 0.406 (91.5%) | α=0.2, HD 0.549 (87.8%) |
| FedAdam | 48.46% | α=0.2, HD 0.549 (87.1%) | α=0.2, HD 0.549 (87.1%) |
| FedYogi | 34.19% | α=0.5, HD 0.406 (79.6%), вновь выше при α=0.2 (102.2%) | α=0.5, HD 0.406 (79.6%), вновь выше при α=0.2 (102.2%) |
| FedAdagrad | 32.49% | α=5, HD 0.119 (93.4%), вновь выше при α=2 (95.9%) | α=0.2, HD 0.549 (82.3%) |
| FedNova | 59.58% | α=1, HD 0.290 (94.5%) | α=0.2, HD 0.549 (86.8%) |
| SCAFFOLD | 49.38% | α=0.5, HD 0.406 (91.4%) | α=0.2, HD 0.549 (83.7%) |
| MOON | 60.20% | α=1, HD 0.290 (94.8%) | α=0.2, HD 0.549 (87.8%) |

Три наименьших Q уже на IID показали FedAdagrad (32.49%), FedYogi (34.19%), FedAdam (48.46%). Значение Q лучшей стратегии на IID составило 60.20%. При низком IID-результате даже сохранение 100% соответствует низкому абсолютному качеству.

Для сбалансированного теста с десятью классами ориентир macro-F1 при равновероятной случайной классификации составляет около 10%. На IID все девять стратегий превысили ориентир равновероятной догадки. На неоднородных разбиениях ниже ориентира оказались FedAdagrad при α=0.1 (Q — 1.82%). Такие точки означают вырождение обучения, а не плавную потерю качества; проверьте матрицу ошибок запуска.

HD взвешен по числу изображений клиента до локального выделения валидации. Доля отсутствующих классов в CSV усреднена поровну по десяти клиентам. Все сравнения описывают одно разбиение на сценарий при seed 42. Для оценки воспроизводимости порогов нужны другие seed.

## Воспроизведение

Команды выполняются из каталога приложения. Для пересборки таблиц и графиков из сохранённых результатов достаточно двух последних команд.

```bash
source venv/bin/activate
out=results/cifar10-sweep-seed42-cpu
config=configs/cifar10_sweep_seed42_cpu.toml
python scripts/prepare_cifar10.py --data-dir data/cifar10 --output-dir "$out/data-preview"
bash scripts/measure_cifar10_sweep.sh "$out"
python scripts/run_benchmark.py --config "$config" --dry-run
python scripts/run_benchmark.py --config "$config"
python scripts/collect_benchmark.py --state "$out/benchmark_state.json" --output "$out/aggregation_benchmark.csv"
python scripts/analyze_cifar10_sweep.py --config "$config"
```
